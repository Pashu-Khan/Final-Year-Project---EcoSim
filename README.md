# EcoSim AI 🌱
### An AI-Assisted Environmental Simulation for Ecosystem Understanding and Restoration

## Overview

**EcoSim AI** is a Computer Science and Artificial Intelligence project focused on developing an interactive environmental simulation in Unity.

The project aims to explore how human activities influence ecosystems over time and how informed interventions can help prevent environmental degradation or support ecosystem restoration.

Players will interact with a virtual ecosystem, observe the consequences of their decisions, investigate environmental changes, and explore possible solutions. Artificial intelligence will support this experience through environmental predictions and natural language explanations grounded in the simulation's data.

The project will investigate whether an AI-assisted simulation can improve users' understanding of environmental cause-and-effect relationships and their ability to identify appropriate environmental restoration strategies.

## Problem Statement

Environmental problems often involve interconnected processes and delayed consequences. An action that appears beneficial or harmless in the short term may contribute to environmental degradation over time.

Understanding these relationships can be difficult when environmental information is presented without opportunities for experimentation or immediate feedback.

EcoSim AI addresses this challenge by providing an interactive environment in which users can experiment with decisions, observe their consequences, investigate why changes occur, and evaluate potential interventions.

## Aim and Objectives

### Main Aim

To develop an AI-assisted environmental simulation in Unity that demonstrates the effects of human activities on an ecosystem and helps users understand how appropriate decisions can support environmental restoration.

### Objectives

- Develop an interactive environmental simulation with measurable environmental variables.
- Model the effects of selected human activities on ecosystem conditions over time.
- Implement a neural network and machine learning model to predict a specific environmental outcome.
- Develop a natural language interface that allows users to ask questions about environmental changes.
- Present environmental conditions, predictions, and consequences through an accessible user interface.
- Evaluate whether interacting with the simulation improves users' environmental understanding and decision-making.

## Research Question

**To what extent can an AI-assisted environmental simulation improve users' understanding of ecosystem cause-and-effect relationships and their ability to identify appropriate environmental restoration strategies?**

## Planned Features

### 🌍 Environmental Simulation
A virtual ecosystem in which environmental conditions evolve in response to player actions.

### 🧑‍🌾 Interactive Environmental Management
Players will be able to perform selected actions that affect the ecosystem, including interventions intended to prevent or reverse environmental damage.

### 🧠 Machine Learning and Neural Computation
A trained model will predict a selected environmental outcome using relevant simulation variables. Its predictions will be evaluated against appropriate reference results or a baseline model.

### 💬 Natural Language Interaction
Players will be able to ask questions about environmental events, such as why water quality has deteriorated or why vegetation has declined. Responses will use recorded simulation data and relevant environmental information.

### 📊 Environmental Feedback and Visualisation
The interface will communicate environmental conditions, changes over time, predictions, and the effects of player decisions.

### 📈 User Evaluation
The prototype will be evaluated using suitable tasks and feedback to investigate changes in users' understanding and environmental decision-making.

*These features describe the intended design; their implementation and final scope may change during development.*

## Technology Stack

The planned technology stack includes:

- **Unity:** Interactive simulation and game development.
- **C#:** Simulation logic, gameplay systems, and integration.
- **Python:** Potential development and evaluation of machine learning models.
- **Machine Learning / Neural Networks:** Prediction of selected environmental outcomes.
- **Natural Language Processing:** Processing user questions and generating grounded explanations.
- **Human-Computer Interaction:** Interface design and user evaluation.
- **Git and GitHub:** Version control, source management, and project documentation.

The final tools and libraries will be selected according to the requirements of the implemented models and the Unity integration approach.

## Planned System Architecture

The project is expected to contain the following main systems:

1. **Environmental Simulation System** — updates environmental variables and models their interactions.
2. **Player Interaction System** — processes environmental actions and interventions.
3. **Environmental State and History System** — records current conditions, actions, and changes over time.
4. **Prediction System** — obtains predictions from the trained machine learning model.
5. **Natural Language Interface** — handles user questions and provides explanations based on available simulation information.
6. **User Interface and Feedback System** — presents environmental indicators, predictions, alerts, and explanations.
7. **Evaluation and Data Collection System** — records appropriate interaction data and supports evaluation of the prototype.

## Project Scope

To keep the project feasible, development will focus on one selected ecosystem and a limited set of environmental variables, player actions, and environmental interactions.

The machine learning component will target a clearly defined prediction task. The natural language interface will support a bounded set of relevant questions, with responses grounded in available data rather than relying on unrestricted AI-generated claims.

The final ecosystem, prediction target, and interaction set will be defined during the project design phase.

## Evaluation

The project will investigate the effectiveness of the prototype through appropriate user tasks and evaluation methods.

Potential evaluation measures include:

- Changes in users' understanding of environmental cause-and-effect relationships.
- Ability to identify appropriate responses to environmental problems.
- Predictive model performance against a defined baseline.
- Accuracy and relevance of answers provided by the natural language interface.
- Usability and clarity of the environmental feedback.

The evaluation will distinguish technical performance from learning outcomes. A successful prediction model does not, by itself, demonstrate that users have learned from the simulation.
